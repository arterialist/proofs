## 1. Mathematical Significance and Overview

For a Lévy jump process on $[0, \infty)$, the characteristic behavior is determined by its Laplace exponent $\Phi(s) = \int_0^\infty (1-e^{-sv})\nu(dv)$. When the jump measure $\nu$ is generated by the full sequence of prime numbers, a fundamental question is how rapidly the finite-prime truncated exponent $\Phi_P(s)$ converges to the all-prime exponent $\Phi(s)$, and whether this convergence is uniform across complex frequencies.

This Lean 4 development proves that:
1. **Half-Plane Kernel Bound:** For all $s \in \mathbb{C}$ with $\operatorname{Re}(s) \ge 0$ and all $v \ge 0$, the Laplace kernel satisfies $\|1 - e^{-sv}\| \le 2$.
2. **Positive Real Part:** For any finite or all-prime jump measure supported on $[0, \infty)$, $\operatorname{Re}(\Phi(s)) \ge 0$ whenever $\operatorname{Re}(s) \ge 0$.
3. **Exact Cutoff Identity:** The error between the all-prime exponent and the prime cutoff $P$ is identically the jump exponent of the prime tail measure:
   \[
   \Phi(s) - \Phi_P(s) = \int_0^\infty (1-e^{-sv})\nu_{\mathrm{tail}, P}(dv).
   \]
4. **Uniform Half-Plane Bound:** For all $P \ge 8$ and all $s \in \mathbb{C}$ with $\operatorname{Re}(s) \ge 0$:
   \[
   \|\Phi(s) - \Phi_P(s)\| \le \frac{64}{\log P}.
   \]
   Crucially, this bound is completely independent of $\operatorname{Im}(s)$, holding uniformly across the entire closed right half-plane, including the imaginary axis $s = -it$.

## 2. Machine-Verified Theorems

### 2.1 Laplace Kernel Bound and Nonnegativity

```lean
noncomputable def laplaceKernel (s : ℂ) (v : ℝ) : ℂ :=
  1 - Complex.exp (-s * (v : ℂ))

theorem laplaceKernel_norm_le {s : ℂ} (hs : 0 ≤ s.re) {v : ℝ} (hv : 0 ≤ v) :
    ‖laplaceKernel s v‖ ≤ 2

noncomputable def jumpExponent (μ : Measure ℝ) (s : ℂ) : ℂ :=
  ∫ v, laplaceKernel s v ∂μ

theorem allPrimeExponent_re_nonneg {s : ℂ} (hs : 0 ≤ s.re) :
    0 ≤ (allPrimeExponent s).re
```

### 2.2 Uniform Right Half-Plane Error Bound

```lean
theorem allPrimeExponent_sub_cutoff (P : ℕ) {s : ℂ} (hs : 0 ≤ s.re) :
    allPrimeExponent s - cutoffPrimeExponent P s = jumpExponent (primeTailLevyMeasure P) s

theorem allPrimeExponent_cutoff_bound (P : ℕ) (hP : 8 ≤ P) {s : ℂ} (hs : 0 ≤ s.re) :
    ‖allPrimeExponent s - cutoffPrimeExponent P s‖ ≤ 64 / log (P : ℝ)
```
