# Building blocks

The notes are grouped by the mathematical object they study. Each subject folder has a short starting page and an alphabetical list of its notes. The [long catalog](catalog.md) keeps the detailed summaries, while the [arithmetic map](arithmetic-subject-index.md) follows dependencies between several branches.

| Subject | Main questions |
| --- | --- |
| [Successor and division](successor-and-division/) | How counting by one meets divisibility and finite Euler transfers. |
| [Factorial and renewal](factorial-and-renewal/) | Factorial weights, division histories, and proposed damping laws. |
| [Prime histories](prime-history/) | How new primes change later composite histories. |
| [Prime distribution](prime-distribution/) | Möbius sums, covariance, sieve estimates, and prime-counting error. |
| [Zeta and zeros](zeta-and-zeros/) | Explicit formulas, continuation, and RH criteria. |
| [Theta and heat](theta-and-heat/) | Theta and xi kernels, heat evolution, and zero-location tests. |
| [Weil and spectral methods](weil-and-spectral/) | Weil forms, Suzuki operators, and prime-shift spectra. |
| [Goldbach and additive pairs](goldbach/) | Additive prime pairs and centered heat identities. |
| [Geometry](geometry/) | Cyclotomic, Farey, and lattice constructions. |
| [Dynamics and feedback](dynamics-and-feedback/) | Source, response, and conservation models. |
| [Analytic methods](analytic-methods/) | Fourier, Mellin, and finite-matrix estimates used elsewhere. |

These folders mix proved results with conditional statements and counterexamples. Read the assumptions and proof-status paragraph in the individual note before using a claim.
