# First formalizations

Completed formalizations for which a documented search supports a first-formalization contribution. Known mathematics is eligible; its original authors and sources must be credited separately from the formalization work.

Review compares equivalent statements and proof dependencies across proof assistants, public libraries, repositories and relevant history. An earlier formalization in another assistant counts as prior formalization. Ports, backports, renamings and wrappers around an existing formalized result belong elsewhere when useful.
