# Reviews

[The current RH claim audit](current-rh-claim-audit.md) records corrections to the recent operator, displacement, and novelty summaries. It states which claims were checked and which remain outside the completed review.

[Literature reviews](literature/) compare specific claims with published mathematics. [Paper audits](papers/) check calculations and proof steps in named papers. [Project history](history/) preserves earlier inventories and cross-references; some paths and counts there describe older repository revisions.

These reviews record what was checked and what remains uncertain. A failed intermediate calculation does not, by itself, refute a paper's final theorem.
